The **dispatch strategy** decides how stock leaves the warehouse after picking. If you dispatch through a carrier shipment, the **shipment strategy** decides who submits the shipment to the carrier. Together they let you remove manual steps, such as completing dispatch tasks one by one after every shipment.

You set both as account defaults, and you can override them on each sales order and order line.

## Set the strategies on an account

<Steps>
  <Step title="Open the account">
    From the **Accounts** screen, open the account you want to update.
  </Step>
  <Step title="Expand the Fulfilment panel">
    Scroll to the **Fulfilment** panel and expand it. It has a **Standard** section and a **Tote** section, so you can set different strategies for standard and tote picking.
  </Step>
  <Step title="Choose a Dispatch Strategy">
    Select a **Dispatch Strategy** for each pick type. See [Dispatch strategies](#dispatch-strategies) below.
  </Step>
  <Step title="Choose a Shipment Strategy">
    If you chose **Shipment** or **Auto Shipment**, select a **Shipment Strategy**: **Auto** or **Manual**. The field is disabled for every other dispatch strategy. See [Shipment strategies](#shipment-strategies) below.
  </Step>
  <Step title="Check the Fulfilment Flow and save">
    The **Fulfilment Flow** below the fields updates as you choose, showing each step the order goes through and whether it happens automatically or manually. Check it matches what you expect, then click **Save**.
  </Step>
</Steps>

New sales orders for the account take these strategies as their defaults. Changing the account does not change sales orders that already exist.

## Dispatch strategies

| Dispatch Strategy | What happens |
|---|---|
| **Auto** | Dispatch tasks are completed automatically once picking finishes, or once packing finishes if the order is packed. |
| **Load** | Stock is grouped into a load and is dispatched when the load is dispatched. See [Dispatching loads](/knowledgebase/outbound/dispatching-loads). |
| **Manual** | A dispatch task is created for each completed pick task, and each one is completed manually. |
| **Shipment** | Stock is packed and added to a carrier shipment. Dispatch tasks are completed manually once the shipment has gone. |
| **Auto Shipment** | Stock is packed and added to a carrier shipment. Dispatch tasks are completed automatically once the shipment is created. |

<Info>**Shipment** and **Auto Shipment** need a **Pack Strategy** (**Pack by Line** or **Pack by Unit**), because packing is what builds the shipment's packages. See [Prerequisites for shipments](/knowledgebase/outbound/pre-requisites-for-shipments).</Info>

## Shipment strategies

The **Shipment Strategy** applies only to the **Shipment** and **Auto Shipment** dispatch strategies. It decides who submits the shipment to the carrier after packing.

| Shipment Strategy | What happens |
|---|---|
| **Auto** | The shipment is submitted to the carrier automatically as soon as all of its packages are packed. |
| **Manual** | You submit the shipment yourself, for example by clicking **Close Package and Print Labels** at the [packing desk](/knowledgebase/outbound/packing-desk). |

## How the two work together

The dispatch strategy controls the dispatch tasks; the shipment strategy controls the shipment. Combining them gives four options:

| Dispatch Strategy | Shipment Strategy | Shipment submitted | Dispatch tasks completed |
|---|---|---|---|
| **Shipment** | **Manual** | Manually | Manually |
| **Shipment** | **Auto** | Automatically | Manually |
| **Auto Shipment** | **Manual** | Manually | Automatically |
| **Auto Shipment** | **Auto** | Automatically | Automatically |

### Choosing a combination

- **You pack at the packing desk** — use **Auto Shipment** with **Manual**. Clicking **Close Package and Print Labels** submits the shipment, and the dispatch tasks complete themselves once the carrier creates it. You no longer need to click **Complete All Dispatch Tasks** for every order.
- **Your orders are mostly single-line** — use **Auto Shipment** with **Auto** to remove every manual step after packing.
- **You want to check orders before they leave** — use **Shipment** with **Manual**, so you control both the shipment and the dispatch.

<Warning>With the **Auto** shipment strategy, the shipment is submitted as soon as everything on it is packed. If an order has several lines that should travel in the same package, use **Manual** so the shipment is not submitted before you have packed them all.</Warning>

<Info>Dispatch tasks complete automatically when the shipment reaches **Created**, which is when the carrier confirms it. While a shipment is still **Submitting**, its dispatch tasks stay open.</Info>

## Set the strategies on a sales order

A sales order takes its strategies from the account when it is created. To change them, open the sales order and use the **Fulfilment** section, which shows the same **Dispatch Strategy**, **Shipment Strategy** and **Pack Strategy** fields alongside the **Default Fulfilment Flow**.

The sales order values are the defaults for new order lines. Each order line keeps its own dispatch and shipment strategy, which you can change in the order lines grid. Where a line differs from the order, the line's strategy is the one that applies.

When you change the **Dispatch Strategy**, the **Shipment Strategy** resets to match:

- **Shipment** sets the shipment strategy to **Manual**.
- **Auto Shipment** sets it to **Auto**.

Change the shipment strategy afterwards if you want a different combination.

<Warning>All stock on one shipment must have the same shipment strategy. If you try to add stock from a line with a different shipment strategy, you see the error *"All stocks in the same shipment must have the same shipment strategy."* Pack those lines into a separate shipment, or align their shipment strategies first.</Warning>

## Additional options

The **Options** section of the **Fulfilment** panel also holds:

- **Pack Strategy** — whether orders are packed, and whether by line or by unit.
- **Dispatch By Output Quantity** — controls how many dispatch tasks are created for assembled (Assemble on Pick) kits. See [below](#dispatch-by-output-quantity).
- **Dispatch Note Footer Notes** — custom text added to the bottom of every generated dispatch note.

<AccordionGroup>
  <Accordion title="Will my existing setup change?">
    No. Accounts and sales orders that already use **Shipment** behave as **Shipment** with **Manual**, and those that use **Auto Shipment** behave as **Auto Shipment** with **Auto**, which is how they worked before the shipment strategy existed.
  </Accordion>
  <Accordion title="What is the difference between Load and Shipment?">
    Both group stock before it leaves. **Load** groups orders onto a vehicle for bulk handling. **Shipment** books one order's packages with a carrier, which suits parcel deliveries.
  </Accordion>
  <Accordion title="Can I undo an automatically completed dispatch task?">
    Yes. Uncompleting a dispatch task works the same way whether it was completed automatically or manually. Automations also trigger as normal.
  </Accordion>
</AccordionGroup>

## Dispatch by output quantity

This setting controls how dispatch tasks are created for products made from a Bill of Materials (BOM) when **Assemble on Pick** is enabled. It determines whether the system creates one dispatch task per pick task, or one per individual component.

| Setting | Behaviour | Best for |
|---|---|---|
| **Off** (recommended) | One dispatch task per pick task | Large dispatches where detailed component tracking is not needed |
| **On** | One dispatch task per individual component for each assembled kit | Detailed tracking and auditing, especially when components are shipped separately |

<Info>This setting does not affect pick tasks — it only changes the number of dispatch tasks created.</Info>
